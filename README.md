# 하노이 탑 🗼

원반을 3번 기둥으로 옮기는 하노이 탑. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `game.js`)입니다.

- 기둥 3개. 처음엔 원반 n개가 큰 것부터 아래로 1번 기둥에 쌓여 있다. **한 번에 맨 위 원반 하나**만 다른 기둥으로 옮기고, **작은 원반 위에 큰 원반은 못 올린다**. 원반을 모두 3번 기둥으로 옮기면 클리어
- 옮기기: 원반이 있는 기둥을 누르고(원반이 들려 올라간다), 옮길 기둥을 누른다. 같은 기둥을 다시 누르면 취소. 키보드는 1·2·3
- 단계는 원반 3~8개(☰ 에서 고른다). 가장 적게 옮기면 **2ⁿ-1번** (3개 7번, 5개 31번, 8개 255번)
- ↩ 되돌리기(Z) 무제한, 🔄 다시(R), 💡 힌트(H): 지금 판에서 **가장 적게 옮기는 길**의 다음 한 수를 분홍 표시로 알려 준다 (중간에 다른 수를 둬도 그 시점에서 다시 계산한다. 판 상태를 '원반마다 어느 기둥인가'(3ⁿ가지)로 보고 너비 우선 탐색)
- ⭐ 별: 최소 이동으로 옮기면 3개, 그 1.25배 안이면 2개, 그보다 많으면 1개. **힌트를 쓰면 최대 2개**. 단계마다 가장 좋은 기록을 저장한다 (`hanoiDone`), 로비에는 깬 단계 수(`hanoiCleared`)가 보인다

규칙과 풀이는 `logic.js`(화면 없이 Node 로 시험할 수 있다), 화면·입력·소리는 `game.js`. 시험은 `node --test` (`test/logic.test.js`: 규칙, 시작 상태에서 최소 이동이 정확히 2ⁿ-1번이고 실제로 풀리는지, 아무렇게나 옮긴 판에서도 힌트를 따르면 가장 짧게 끝나는지).
